goit-algo-hw-03

Домашнє завдання: реалізація трьох функцій на Python з використанням модулів datetime, random та re.

Завдання 1 — get_days_from_today

Розраховує кількість днів між заданою датою та поточною датою.

Файл: task_1.py
Запуск: python task_1.py
Приклад: get_days_from_today("2021-10-09") → кількість днів від сьогодні до цієї дати (від'ємне число, якщо дата вже минула).
Завдання 2 — get_numbers_ticket

Генерує набір унікальних випадкових чисел для лотереї у заданому діапазоні.

Файл: task_2.py
Запуск: python task_2.py
Приклад: get_numbers_ticket(1, 49, 6) → [4, 15, 23, 28, 37, 45]
Завдання 3 (додаткове) — normalize_phone

Нормалізує телефонні номери у різних форматах до стандартного вигляду +380XXXXXXXXX.

Файл: task_3.py
Запуск: python task_3.py
Приклад: normalize_phone("    0503451234") → +380503451234
Вимоги
Python 3.10+
Без зовнішніх залежностей (використовуються лише вбудовані модулі)
